## 图 2：端到端数据流（上游 → 屏幕）

```mermaid
flowchart LR
    classDef step fill:#e8f4ff,stroke:#69a
    classDef core fill:#e9fbe9,stroke:#6a6

    F["你的文件<br/>场景 / MAA / v3 输出 / v4 蓝图"] --> DF["detect_format<br/>sources.py:256"]
    DF --> I1["_import_scenario:421"]
    DF --> I2["_import_maa:496"]
    DF --> I3["_import_v3:630"]
    DF --> I4["_import_v4:729"]
    I1 & I2 & I3 & I4 --> ASM["load_schedule_from_imports:473<br/>shifts_from_import → Shift"]
    ASM --> SCH["Schedule<br/>班次 + 每班 facilities"]
    SCH --> SESS["Session.load_paths:147<br/>_sync_from_schedule:240"]
    SESS --> RI["recompute_inputs:339<br/>逐段指纹 → 增量切点"]
    RI --> SIM["simulate_schedule:968<br/>事件驱动精确积分"]
    SIM --> SEG["段循环：每个换班执行点<br/>deepcopy(pristine) → 重建布局"]
    SEG --> EV1["apply_entry_events<br/>进驻事件（换心情 / 位置）"]
    SEG --> EV2["apply_idle_to_dorm<br/>闲置入宿（填空床 / 换人）"]
    EV1 & EV2 --> TRAJ["Trajectory<br/>times · moods · marks · segments"]
    TRAJ --> SER["store/serialize.py<br/>或 api export_schedule"]
    TRAJ --> UI1["ui 看板 world_at(t)"]
    TRAJ --> UI2["ui 曲线 mood_at/rate_at"]
    TRAJ --> UI3["ui 设置中心<br/>idle_groups / 位置列"]
    TRAJ --> API1["api layout_at / moods<br/>operator_detail / closure"]

    class F,DF,I1,I2,I3,I4,ASM,SCH,SESS,RI,SIM,SEG,SER,UI1,UI2,UI3,API1 step
    class EV1,EV2,TRAJ core
```

**读法**：从左到右是**一条直线**——文件 → 识别 → 装配成 `Schedule` → 进 `Session` →
算增量切点 → 积分成 `Trajectory` → 分发给界面与接口。
唯一的"两个分叉"是段循环里的两个**布局事件**（进驻事件、闲置入宿），它们只在
`pristine` 的**深拷贝副本**上生效，永不写回你导入的排班。

## 图 3：一次重算的时序（谁调谁）

```mermaid
sequenceDiagram
    autonumber
    participant U as 用户（界面）
    participant APP as ui/app.py
    participant SES as store/session.py
    participant SIM as store/schedule.py
    participant ENG as mood_soc/rules.py

    U->>APP: 改一个格子 / 点一个槽位（或导入文件）
    APP->>SES: apply_* / set_* （写设置或布局）
    Note over APP,SES: ⚠️ 面板里的改动先写"局部工作副本"，<br/>再由 apply_* 交给 Session
    APP->>SES: recompute_async()（工作线程）
    SES->>SES: recompute_inputs()：逐段指纹 → 算切点
    SES->>SIM: simulate_schedule(continue_from=切点)
    loop 每个换班执行点（班初 + 长班 12h 整数倍）
        SIM->>SIM: deepcopy(pristine[idx]) 重建位置
        SIM->>ENG: apply_entry_events()
        SIM->>ENG: apply_idle_to_dorm()
        ENG-->>SIM: 事件流水账（marks）
    end
    SIM-->>SES: Trajectory
    SES-->>APP: adopt(traj, sigs)（主线程落地）
    APP->>U: 重画：看板 / 曲线 / 全员一览 / 状态栏
    Note over APP,U: ⚠️ 落地前若面板还在防抖（心情 500ms / 闲置入宿 250ms），<br/>先攥住结果不刷，等面板提交再落地
```
