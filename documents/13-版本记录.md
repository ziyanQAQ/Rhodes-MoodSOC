## 未发布（2026-10）：闲置入宿「三层解耦」

**一句话**：把「手动入宿」与「自动入宿」解耦成三层，明确优先级
**手动编辑 > 自动入宿 > 导入布局**；手动入宿从"设置面板里的第二套写法"改成
**布局编辑本身**（写班次快照 + 手动台账），自动入宿重写成可判定、可终止的两相算法。

| 项 | 旧（v1.1 及以前） | 现 |
|---|---|---|
| 手动入宿 | 闲置入宿面板的逐次表：`宿舍NN` / `宿舍NN·第M位` / 点名某人（引擎按配置执行） | **看板 / 「干员与心情」**写**班次布局 + 手动台账**（`facilities[].slots` / `manual`）；面板那一列已删 |
| 手动标记 | 无（导入与手改在数据里同形） | `models.ManualLedger {slots, names}` 挂在设施上；**导入不打标**；钉住的位次/人自动入宿不碰 |
| 换人目标 | 竖向**反序**扫描，取首个**严格大于**候选的住户 | 取"**≥ 候选且心情最大**"的住户（并列取竖向正序最靠前）—— 这样才达到"宿舍装进全体里心情最低的那批"的定点 |
| 被换出者 | 追加队尾，可能在同一执行点被再处理 | **不在本执行点再入队**（下一个执行点重新评估）—— 实测"插回队列"永远改变不了结果，只会打转 |
| 空位 | "连续排列"：唯一可入住位＝现有人数 + 1 | **竖向正序第一个空位**（含中间空洞）；清空某位**不左移**（`models.set_seat`） |
| 面板逐次表 | 每行「位置 / 换谁」下拉 | 每行只有「参与」+ 一列**只读**的"引擎安排了什么"（`Trajectory.idle_note_at`） |
| API | `set_idle_to_dorm` 的 `per_operator[].target` 三类 | `per_operator` **只剩"参不参与"**；旧写法读得进来但被忽略，回一条 `notes` |
| 锁定位置 | 键是 `id(facility)` ⇒ **静默失效**（排班层先在 pristine 上算、再在每段深拷贝上跑） | 键是 `rules._seat_key(world, fac)`＝`(类型, 实例名)` 或 `(类型, 世界下标)` |

代码落点：`mood_soc/rules.py`（`_seat_verdict` 是三层唯一裁决点、两相自动入宿、`_seat_key`）、
`mood_soc/models.py`（`ManualLedger` / `set_seat` / `remove_occupant` / `facility_occupancy` /
`IdleToDormEntry` 收窄）、`store/session.py`（`set_slots` / `set_facility_slots` / `_write_seats` /
`_write_manual` / `_trim_to_capacity`）、`store/schedule.py`（`idle_notes`）、
`api/ops.py`、`ui/dialogs.py`、`ui/app.py`。
自检：`scripts/verify_idle.py` 整段重写（78 条；后续的「手动入宿解耦与显式上锁」批次又扩到 **128 条**）；全量 `unittest` 绿；

### 手动入宿「解耦与显式上锁」（2026-10，15 个提交）

**一句话口径**：**手动编辑 > 自动入宿 > 导入布局**；手动编辑＝**摆位即上锁**（含"清空即上锁"）

### 5. 线程与关窗口健壮性（**修"崩进程"**）

- `destroy()` 还要撤掉挂着的 `after_idle`，并**上闩**（`RosterStrip._closing`）——

### 10. 发布阻断修复：设置窗口的 Shift+Tab 绑定（构建期发现）

`ui/settings.py` 里 `self.bind("<ISO_Left_Tab>", …)`：`ISO_Left_Tab` 是 X11 的 keysym 名，
**Windows 的 Tk ≤ 8.6.12 没有它** ⇒ 抛 `TclError`，而这行在设置窗口的 `__init__` 里
⇒ **整个「设置…」打不开**（本次全量测试里 21 个 GUI 用例同时红，就是这么发现的）。
v1.0 的 exe 用 Python 3.14（Tk 8.6.13+）构建，那边认得这个名字，所以一直没暴露。
修法：按 `<Shift-Tab>` → `<Shift-Key-Tab>` → `<ISO_Left_Tab>` **逐个 try、绑上第一个就 break**
（只绑一个：两个都绑在 X11 上可能触发两次）。
